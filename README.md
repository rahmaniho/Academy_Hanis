# Hanis Beauty Academy

A responsive Persian landing page for Hanis Beauty Academy. Run locally with `python3 -m http.server 8000` and open the site in a browser.

The consultation form is a front-end prototype and does not transmit or store submissions. Connect it to an approved backend or contact channel before launch. Course and service descriptions are illustrative and should be reviewed. Editorial imagery should be replaced with properly licensed brand photography before production.
